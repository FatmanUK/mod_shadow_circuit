# Bootstrap Markdown Manifest — "Shadow Circuit" ProTracker Module

## 1. Current Goal
Compose a suspenseful, thumping, looping load-screen tune titled **"Shadow Circuit"**,
in the style of Ray Norrish / Alistair Brimble, as source for a genuine **ProTracker 2**
4-channel `.mod` file. Nine unique 64-row patterns, ~90 seconds of arranged playtime,
built entirely from 8 real samples taken from the ST-01/ST-02 Ultimate Soundtracker disks.
Patterns are being composed and reviewed **one at a time** — the user auditions each
pattern by eye/ear in MilkyTracker before the next is written.

Currently on: **Pattern02 ("Dark Variation")** — not yet written.
Pattern00 and Pattern01 are both confirmed/passed.

## 2. State of Play

### Format rules (ProTracker 2 constraints, confirmed by user)
- Notes restricted to **octaves 3–5** (MilkyTracker numbering; C-4 = period 428 reference).
- **Forward loops only** (no ping-pong).
- **4 channels only.** No XM-only effects — Amiga ProTracker-compatible effect set only.
- Plausible as an early-1990s Amiga game disk tune.
- Pattern text notation for MilkyTracker entry:
  `RR | NNN SS ECC | NNN SS ECC | NNN SS ECC | NNN SS ECC`
  (Note 3-char or `...`; Sample 2-digit hex or `..`; Effect 1-digit cmd + 2-digit hex param or `...`)

### Tempo
**Speed 6, Tempo 125** (set once via `Fxx` at Pattern00 row 00; carries forward automatically
in ProTracker replay — not restated in later patterns unless it needs to change).
Each row = one 16th note; 64 rows = 4 bars = 7.68 seconds per pattern-play.

### Loop recommendations (loop *point* data deferred to user)
- **NightMare** — needs a forward loop; envelope sustains (33–46 RMS) rather than decaying, needed for continuous atmosphere.
- **Siren** — needs a forward loop; decays naturally but its function (held tension riser) requires it not to die out.
- All other 6 samples (BassDrum4, Snare3, CloseHiHat, DeepBass, Perc-Timpani, Mechanic2) decay cleanly to near-silence — **no loop needed**, used as one-shots.

### Effects introduced so far (must explain each on first appearance)
- **`Fxx`** — Speed/Tempo. Param 00–1F sets Speed (ticks/row); 20–FF sets Tempo (BPM).
  Introduced Pattern00 row 00 (`F06` speed 6, `F7D` tempo 125).
- **`Cxx`** — Set Volume. Sets that note's volume directly (00–40 hex = 0–64 decimal),
  overriding the sample's default for that single trigger only — must be restated on
  every row where the override is wanted, since a new note-on otherwise reverts to the
  sample's default volume. Introduced Pattern01, alternating hi-hat accents (`C38`/`C20`).
